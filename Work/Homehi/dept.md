**日期**: 2026年7月27日

**說明**: 本文件整理了鴻海集團在電子產品開發、射頻工程、硬體測試及軟體領域的常見專有名詞與部門縮寫。

---

## 1. 電子與系統工程 (Electrical & System Engineering)

| 縮寫/術語 | 全稱/解釋 | 主要職責與內容 |
| :--- | :--- | :--- |
| **EE** | **Electrical Engineering** | 電子工程部門，涵蓋電路設計、電源管理、訊號完整性等基礎電路開發。 |
| **EE Inductive** | **EE Inductive Engineering** | 負責感應與電感相關技術，包括無線充電線圈、NFC/RFID 感應線圈及電感元件設計。 |
| **EE Motion Sensor** | **EE Motion Sensor Engineering** | 負責運動感測器整合，如加速度計、陀螺儀、電子羅盤及 IMU 的電路設計。 |
| **EE OSD** | **On-Screen Display / Optical Sensing** | 負責螢幕顯示控制電路 (OSD) 或光學感測元件的電子工程開發。 |
| **EE System** | **EE System Engineering** | 系統級電子工程，負責整機電路架構、電源分配 (Power Budget) 及各子系統整合。 |
| **HWTE** | **Hardware Test Engineering** | 硬體測試工程，負責硬體功能驗證、可靠度測試及自動化測試系統開發。 |
| **IE** | **Industrial Engineering** | 工業工程，負責產線佈局、作業流程優化、工時分析、產能規劃及成本降低。 |

## 2. 射頻與天線工程 (RF & Antenna Engineering)

| 縮寫/術語 | 全稱/解釋 | 主要職責與內容 |
| :--- | :--- | :--- |
| **RF** | **Radio Frequency** | 射頻部門總稱，涵蓋所有無線通訊相關的射頻技術開發與測試。 |
| **AAE** | **Advanced Antenna Engineering** | 先進天線工程部門，負責高階天線設計與類比電路技術開發。 |
| **AAE Module** | **AAE Module Engineering** | AAE 下的模組化團隊，專注於整合式天線模組 (如 AiP) 的開發。 |
| **EERF** | **Electrical Engineering RF** | 電子工程下的射頻分支，專注於射頻電路設計與整合。 |
| **MLB RF** | **Main Logic Board RF** | 主機板射頻部門，負責主機板上的射頻電路佈局、走線、接地與屏蔽設計。 |
| **RFHW** | **RF Hardware** | 射頻硬體設計，泛指射頻電路前端的硬體開發。 |
| **RFSW** | **RF Software / Switch** | 射頻軟體 (韌體/演算法控制) 或射頻開關設計部門。 |
| **RF BBHW** | **RF BaseBand Hardware** | 射頻基頻硬體，負責基頻處理器與射頻前端間的介面電路及濾波設計。 |
| **RF CoEx** | **RF Coexistence** | 射頻共存技術，解決 Wi-Fi/Bluetooth/5G 等多技術同時運作時的干擾問題。 |
| **RF Desense** | **RF Desensitization** | 射頻靈敏度劣化分析，解決內部雜訊源對接收靈敏度的影響。 |
| **RF Wipas** | **Wireless Power and Sensing** | 無線充電與感測技術 (如 Qi/WPC, UWB 定位)。 |
| **RF mmWave** | **RF Millimeter Wave** | 毫米波射頻部門，負責 5G NR mmWave 天線、波束成形及相控陣列設計。 |

## 3. 天線測試與認證設施 (Testing & Certification Facilities)

| 縮寫/術語 | 全稱/解釋 | 主要職責與內容 |
| :--- | :--- | :--- |
| **Antenna Chamber** | **Antenna Test Chamber** | 天線暗室/電波暗室，用於無反射環境下的天線輻射場型量測。 |
| **EMC** | **Electromagnetic Compatibility** | 電磁相容部門，負責 EMI/EMS 測試、干擾抑制及法規認證 (FCC, CE 等)。 |
| **RSE** | **Radiated Spurious Emission** | 輻射雜散發射測試，確保設備非預期輻射符合法規限制。 |
| **WSCE** | **Wireless System Certification Engineering** | 無線系統認證工程部門總稱。 |
| **WSCE Anechoic** | **WSCE Anechoic Chamber** | 全電波暗室設施，用於自由空間輻射特性量測。 |
| **WSCE CATR** | **WSCE Compact Antenna Test Range** | 緊縮場天線測試設施，利用反射面模擬遠場，適合 mmWave 量測。 |
| **WSCE cSar** | **WSCE specific Absorption Rate** | 比吸收率 (SAR) 測試設施，量測電磁波對人體的熱效應吸收。 |
| **RF Antenna Testing** | **RF Antenna Testing** | 天線性能測試，包含 TRP/TIS、效率、增益等量測。 |
| **RF Antenna FA** | **RF Antenna Failure Analysis** | 天線失效分析，針對產線不良或客訴進行根因解析。 |

## 4. 產品開發專案 (Product Development - KPD)

*註：KPD 通常指核心產品開發 (Key Product Development) 或特定專案代號部門。*

| 縮寫/術語 | 全稱/解釋 | 主要職責與內容 |
| :--- | :--- | :--- |
| **KPD** | **Key Product Development** | 核心產品開發部門，專案導向的技術整合單位。 |
| **KPD Acoustic** | **KPD Acoustic Engineering** | 聲學產品開發，負責揚聲器、麥克風、音腔設計及降噪技術。 |
| **KPD Camera** | **KPD Camera Engineering** | 相機模組開發，涵蓋鏡頭、感測器、OIS/AF 及機構整合。 |
| **KPD Display** | **KPD Display Engineering** | 顯示器開發，負責 LCD/OLED/Mini-LED 面板整合與驅動技術。 |
| **KPD Arc** | **KPD Arc Project** | 可能指弧形/曲面產品開發，或特定研發中心代號。 |
| **KPD Jasper** | **Project Jasper** | 內部專案代號 (常見於特定客戶保密產品，如 Apple 供應鏈)。 |
| **KPD Pearl** | **Project Pearl** | 內部專案代號，可能涉及特定機構或光學技術產品。 |
| **KPD TritiumA** | **Project Tritium A** | 內部專案代號 A 版，可能涉及無線充電或特定能源技術。 |

## 5. 軟體工程 (Software Engineering)

| 縮寫/術語 | 全稱/解釋 | 主要職責與內容 |
| :--- | :--- | :--- |
| **SW** | **Software** | 軟體部門總稱。 |
| **SW CoreOS** | **Core Operating System** | 核心作業系統部門，負責 OS 底層移植、驅動程式 (Driver) 及 BSP 開發。 |
| **SW Diag** | **Software Diagnostics** | 軟體診斷工具，開發產線測試程式、維修診斷腳本及故障檢測軟體。 |
| **SW Wireless** | **Wireless Software** | 無線通訊軟體，負責協定堆疊 (Wi-Fi/BT/NFC)、連線管理及韌體更新 (FOTA)。 |

## 6. 管理與品質控制 (Management & Quality)

| 縮寫/術語 | 全稱/解釋 | 主要職責與內容 |
| :--- | :--- | :--- |
| **PD** | **Product Design / Development** | 產品設計或產品開發部門。 |
| **PD IT** | **Product Development IT** | 產品開發資訊技術，負責 PLM/PDM 系統、設計自動化工具及資料管理。 |
| **OQC** | **Outgoing Quality Control** | 出貨品質管制，負責產品出廠前的最終檢驗，確保符合客戶規格。 |
